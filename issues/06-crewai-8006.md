## What it is

A maintainer-authored, explicitly beginner-labeled "student project": build a small shared set of **behavioral
compatibility tests** that compare how native LLM providers (OpenAI, Anthropic) behave, then fix confirmed gaps via
focused implementation PRs. Team 1–2 contributors.

Deliverables are pre-split into PR milestones:

- PR1 — shared contract test: plain-text requests, returned text, sync/async on two providers using fake SDK responses.
- PR2 — `LLMMessage.content` as text, multimodal parts, and `None`; preserve model content, use `message_content_text`
  only when a consumer specifically needs text.
- PR3 — tool-call IDs/results, streaming completion, token usage, one failure event per failed logical path.

Prereqs (stated in issue): Python, pytest, mocks, async basics, familiarity with `BaseLLM`.
